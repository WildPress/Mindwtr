# Mindwtr 1.3.2

Mindwtr 1.3.2 simplifies task screens, speeds up Focus, improves capture and calendars, and makes sync, storage, and upgrades more dependable across desktop and mobile.

## Highlights

- Task screens show fewer controls at once, History combines Done and Archived, desktop gains direct Sort and Group controls, and mobile uses a compact menu grid.
- Focus grouping is faster, search accepts `@context`, `#tag`, and `%person` shorthand, and status icons now mean the same thing throughout both apps.
- Apple Reminders can import automatically, Android background captures sync without opening the app, and email and webhook retries no longer create duplicate tasks.
- Windows and macOS use separate `config` and `data` folders with a safe one-time migration. MCP 1.1.10 and command-line tools understand the new layout.
- Calendar views handle moved and cancelled recurring events, dense all-day rows, narrow layouts, Apple Calendar colors, and date navigation more reliably.
- WebDAV encryption, self-hosted attachment refusal, iCloud push delivery, mobile background timeouts, and file-sync diagnostics are more resilient.
- Desktop gains installed-font selection, a Save log action, clearer filters, steadier loading indicators, and more reliable Save & edit navigation.
- Danish is now available, bringing Mindwtr to 23 languages on desktop and mobile.

## Navigation, tasks, and GTD workflow

- Task screens show fewer choices at once. Desktop gains direct **Sort** and **Group** controls, simpler filters, and a tidier project layout. Done and Archived are tabs in one **History** destination, and the mobile Menu is a compact grid.
- **Start later** in Inbox processing now offers Project and Area choices.
- **Save & edit** follows a task to the list that shows it, including future-start tasks.
- A task filed directly under an area now names the area on its mobile row.
- **Clear Trash** removes only visible filtered or searched items and explains retention. With no filter it still clears all Trash.
- Undoing a project deletion restores its tasks to that project.
- Dragging a desktop task onto **History** completes it, and collapsed sidebar groups open during a drag.
- Filters that do not apply to the current list appear muted and no longer claim to be active, including in Archived.
- Time estimate choices match across both apps and include 15 minutes.
- Status icons now have one meaning across editing, Inbox processing, and navigation. Waiting uses a pause circle, Incubate a seedling, and the hourglass is reserved for time estimates.
- Moving a dated task to **Someday** now sticks instead of reverting to Next on reload.
- Mobile Focus offers **Today** in the long-press Start Date menu, respects due-date bounds, and works for tasks that already have a due date.
- Starred projects appear first within each area on mobile; other projects retain desktop drag order and then name order.
- Weekly Review keeps stale tasks in place while they are edited, until the review ends or their workflow status changes.

## Search, capture, and editing

- Search supports `@home`, `#tag`, and `%name` as shorthand for context, tag, and person filters on desktop and mobile.
- Desktop title entry suggests People for `%`, fills **Assigned To**, and removes the accepted token.
- Desktop Quick Add refreshes suggestions for each slash command instead of keeping results from the first command.
- The desktop edit shortcut works inside calendar pop-ups.
- Arrow keys work in the desktop **Dates…** submenu, dialogs no longer close an underlying Filters panel, and font selection keeps the highlighted item visible.
- Mobile task Preview keeps checklist input above the keyboard suggestion bar and saves unsubmitted checklist text when **Save** is pressed.
- Email capture creates one task across retries, crashes, and multiple computers, and downloads only the first part of a message instead of its attachments.
- Capture webhooks accept a `captureId` so a repeated delivery does not create a duplicate.
- Permanently deleted tasks and projects cannot be recreated as empty “(deleted)” items from stale links.
- Todoist imports and spoken due dates without a time remain date-only and do not acquire a reminder.

## Focus, projects, and interface

- Focus does less repeated work while grouping large task lists; the measured test-phone calculation was about 45% faster with the same output. Widget list building also benefits from the faster no-filter path.
- Desktop **Settings → General → Look & feel** can browse, search, and apply installed fonts. The synced choice falls back safely where a font is unavailable.
- The font picker offers fonts with a real bold face, avoiding blurry synthesized headings while preserving an existing selection.
- Shortcut help documents `h`/`←` and `l`/`→` panel navigation.
- Desktop and mobile replace emoji controls with the same drawn icon set used elsewhere in the app.
- Desktop loading spinners rotate cleanly on scaled Windows displays, the sidebar sync indicator stays steady between queued syncs, and surrounding task text no longer blurs.
- The occasional support prompt appears at most once every six months across devices sharing the same data. Opt-out diagnostics use one identifier per shared data set.
- About places Terms of Use beside Privacy and shows the destination address for every row.

## Calendars, reminders, and widgets

- Apple Reminders can import automatically after the user chooses a list and enables **Import automatically**. It requests no permission on its own and serializes manual and automatic imports.
- Apple Reminders records an item as imported only after its Mindwtr task is safely saved.
- Mobile schedule view lists scheduled days before the planning list.
- Compact widget dates follow the date format in Settings, including after background sync.
- Calendar tasks stay hidden from imported events when a calendar service adds trailing blank lines or spaces to their notes.
- Moved instances of subscribed repeating events appear once at the new time, while cancelled or deleted instances disappear.
- Desktop all-day rows show a **+N more** control and reveal every hidden item.
- Desktop selected-day rows keep names visible in narrow windows, and Schedule search moves beside the list only when space allows.
- macOS date-picker arrows change month without closing the picker.
- macOS Apple Calendar chips keep name order and use each calendar's own color.
- The iPhone and iPad Control Center **Add Task** control routes to quick capture. Device confirmation is still requested for this fix.

## Sync, storage, and attachments

- WebDAV encryption can be enabled when the remote folder has never contained an attachment.
- Self-hosted sync sets aside an attachment after three permanent size or file-type refusals so other changes can continue syncing; the local file remains intact.
- File Sync diagnostics name the rule behind a refused attachment upload.
- Missing attachment files no longer produce repeated localized Windows warnings or expose their full path in diagnostics.
- iCloud changes reach iOS through silent push delivery, with registration refreshed at each launch independently of notification settings.
- iOS and Android background sync abandon a suspended iCloud request within a few minutes and retry on the next cycle.
- Custom AI endpoint addresses remain local to each device like API keys, preventing a synced endpoint from receiving another device's credential.
- Diagnostic redaction recognizes newer OpenAI, Anthropic, xAI, Groq, and OpenRouter key formats without cutting ordinary words.
- Nine duplicate desktop search indexes are removed on first launch to reduce save overhead.

## Profile migration, MCP, and automation

- Installed Windows and macOS builds now keep settings under `config` and data under `data` within the profile folder. First launch moves existing files once; Linux and portable layouts are unchanged.
- The migration preserves attachments, voice notes, and downloaded speech models, keeps recordings after transcription failure, and coordinates simultaneous launches.
- If MCP holds the Windows database open, migration rolls back and retries safely on the next launch after MCP exits.
- Command-line tools, the script API, and MCP find the migrated database through pinned, Flatpak, and sandboxed macOS paths. MCP accepts leading `~` in `--db` paths.
- Command-line task saves preserve every field and reject an older task over a newer copy.
- MCP users on Windows or macOS need `mindwtr-mcp` 1.1.10 or later for the new profile layout.

## Mobile and platform reliability

- Android speech-model download failures show an error and retry action instead of closing the app.
- Speech-to-text tries `hf-mirror.com` when Hugging Face is unreachable and still verifies the model SHA-256.
- Android tasks captured from an app shortcut, widget, or Quick Settings tile sync immediately. Closed-app widget completion and capture queues sync during the next background run.
- Mobile restores History after Android process recreation and again shows the active-filter count in Inbox.
- Linux reminder notifications carry the Mindwtr logo.

## Languages

- Danish is complete across desktop and mobile, bringing Mindwtr to 23 languages.

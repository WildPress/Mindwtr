# Mindwtr 1.3.3

Mindwtr 1.3.3 improves task selection, Focus planning, recurrence, calendars, widgets, sync, storage, and desktop integration, with safer recovery when devices or processes edit the same data.

## Highlights

- Waiting For tasks show their assigned person even when row details are hidden, desktop supports modifier-click selection and double-click editing, and Vim shortcuts can copy the selected task.
- Focus can queue future-start tasks, collapse sections on desktop, evaluate an editor's draft recurrence and star, and keeps the selected Group value visible.
- Monthly repeats support positioned weekdays, recurring follow-ups keep a canonical shape, and a fixed occurrence can be skipped without breaking the series.
- Calendar visibility can be limited by Area, Daily Review shows every calendar event, and task blocks and current-time lines sit on their exact minute.
- Widgets use the app's language and 12/24-hour setting, while queued captures, check-offs, deferrals, Watch audio, and context automations replay more safely.
- Saved filters, restored settings, sync opt-outs, encrypted WebDAV recovery, CloudKit retry delays, and concurrent saves preserve the latest intended data.
- Linux follows portal theme changes and stores Flatpak credentials through the Secret Service portal; Windows profile migration waits safely for another process.
- Search, editor navigation, recurrence controls, accessibility labels, link entry, AI language, and mobile review flows receive focused fixes throughout the apps.

## Tasks, Focus, and navigation

- Waiting For rows show assigned people on desktop and mobile even when extra details are hidden.
- Desktop supports modifier-click range selection, opens a task editor on row double-click, and adds Vim shortcuts to copy a selected task's title or title and notes.
- Focus can include future-start tasks, prioritizes the Next section consistently, preserves collapsed desktop sections, and shows the active grouping choice instead of clipping it behind a long label.
- Task editors evaluate Focus from the unsaved recurrence and star draft, so the preview matches what Save will produce.
- Reordering a filtered project list preserves hidden tasks and sequential-project cues follow the actual sequence rather than the visible sort.
- Parent context and tag filters appear in autocomplete without replacing explicit child selections; quoted shorthand searches decode correctly.
- Saved Focus filters discard hidden selections when applied, while deleted saved filters, group keys, and template text remain isolated and literal.
- Reference grouping persists on mobile, focused-project warnings recognize Waiting actions, and compact recurring rows retain their recurrence marker.

## Editing, recurrence, and review

- Monthly recurrence supports positioned weekdays such as the second Tuesday, and recurrence edits keep patterns, tokens, strategy, end rules, and custom values intact.
- A single fixed occurrence can be skipped, recurring follow-ups are stored canonically, and editor updates carry reminder intent explicitly.
- Checklist edits change only the tapped item; Reset checklist reopens items added in the editor; failed mobile checklist writes show the stored result.
- Bulk organize shows localized dates, preserves typed tags after a failed write, and announces mobile bulk actions and selected tokens to assistive technology.
- Status changes can open directly from the mobile swipe action, while macOS status menus follow the app theme.
- Review and Inbox processing keep date-only values date-only, preserve stored clock times, wait for calendar data, and show clearer translated counts and prompts.
- Daily Review shows all calendar events, and mobile fixes cover Mind Sweep, saved-search navigation, Focus checklists, and Review accessibility.

## Calendar, widgets, and mobile behavior

- Calendar visibility can be filtered by Area and new calendar items inherit the intended Area defaults.
- Day and Week hour lines, task blocks, and the current-time line use the exact wall-clock minute; weekday headers remain correct after a time-zone change.
- External calendar event handoff on iOS is reliable, and Calendar fixes cover duplicate month rows, completed-item actions, first-load errors, 12/24-hour composer times, DST movement, and Jalali headings.
- Widgets use the app or device language and the app's explicit or system 12/24-hour clock setting.
- Apple Shortcuts can open a saved list directly, and audio capture can start in Focus mode.
- Context-automation notifications open the right context, bare and `@` forms count as one trigger, and links containing spaces decode correctly.
- Queued check-offs and deferrals cannot overwrite a later task edit, replayed captures do not create a second project, and Watch audio is retained once if the app stops before queue cleanup.
- Mobile status menus, project Area ordering, draft Focus stars, app-lock announcements, and system-following OLED dark appearance are improved.

## Desktop and Linux

- Search navigation and other exits refuse to discard an unsaved desktop task edit.
- Global search and project lists preserve scroll position while inactive, and desktop sync errors are coalesced instead of repeating.
- Context and tag tokens are quoted for desktop full-text search, including literal `@` and `#` values.
- Linux native titlebars react to portal theme changes, and Flatpak stores credentials through the Secret Service portal with the required sandbox access.
- Windows profile migration keeps waiting while another process removes the layout lock instead of treating the transient lock as failure.
- Font choices apply correctly when the installed-font list finishes loading after the setting is restored.

## Sync, storage, and recovery

- Desktop and shared-core saves never delete live rows, referenced parents, or saved filters merely because a stale whole-document snapshot omitted them.
- Exact desktop saves compare against the data they replace, so concurrent captures and other external writes survive.
- Restored settings and device opt-outs survive later sync cycles; saved filters keep unknown fields, stored order, and conflict winners without v1.3.2 rewrites.
- Verified encrypted WebDAV reads can recover stale plaintext transition state, and CloudKit preserves server retry delays while avoiding redundant record writes.
- Mobile sync services, attachments, background policy, automatic triggers, and Settings rules now route through shared core contracts while keeping their existing platform transports.
- Startup writers wait until canonical SQLite loading completes, preventing early writes from racing migration or recovery.
- Delete forever rechecks that a task is still in Trash, section deletion compares JSON identifiers by value, and snapshot recovery and cancellation retain their intended rows.

## Capture, automation, and developer interfaces

- Scheduled API captures apply the same Focus and limit rules as the apps.
- Multiple links can be pasted into Add link dialogs, AI responses use the app language, and local search and quick-add handle quoted shorthand consistently.
- MCP local and self-hosted adapters share task/project behavior for search, recurrence, checklist, Area, review, Focus, and link fields; package version 1.1.10 remains the independent published server version.
- The native Android and SwiftUI migration clients gained broader read/write, replay, filtering, sorting, review, settings, and recovery parity behind isolated development app identifiers; they do not replace the production React Native app in this release.
- Release automation keeps new Play and Microsoft rollouts at 5% for the first 24 hours, strengthens Xcode 27 and private Mac validation, and expands native platform regression checks.
